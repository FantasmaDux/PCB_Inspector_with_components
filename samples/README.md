# Демонстрационные пары

`demo_*.png` созданы скриптом `scripts/make_demo.py`. Это **синтетические иллюстрации** платы с компонентами, не фотографии настоящего устройства. Они свободно распространяются как часть этого проекта под MIT.

- `demo_reference.png` — условная исправная сборка.
- `demo_normal.png` — тот же растр с небольшой поправкой яркости.
- `demo_missing.png` — программно удалён один условный компонент.
- `demo_displaced.png` — смещён компонент и повёрнут весь снимок.
- `demo_wrong_reference.png` — другая иллюстрация для негативного теста.

Эти данные нужны для первого знакомства и автоматических тестов. Они не подтверждают качество сравнения настоящих плат. Алгоритм не читает имена сценариев, готовые рамки или ответы: API получает только два растра, параметры и сведения о ревизии.

Реальные данные, условия съёмки и источники — в `docs/DATASETS.md`. Собственные снимки и внешние скачанные данные храните в `local_data/`, которая исключена из Git и архивов.

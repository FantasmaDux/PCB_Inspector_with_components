# Данные для плат с компонентами

## Для текущего режима

Обучающий набор не нужен: требуется исправный эталон той же платы и ревизии. Нужны также совпадающая комплектация, похожий ракурс, масштаб и свет. Встроенные картинки `demo_*.png` — синтетическая иллюстрация, созданная в проекте. Реальными фотографиями дефектов они не являются.

Для проверки на своих платах организуйте локальную папку:

```text
local_data/
  board-A-rev2/
    golden.jpg
    normal-01.jpg
    missing-component-01.jpg
    shifted-component-01.jpg
```

Локальные снимки и производственные сведения не включаются в Git и архивы. Список соответствий golden/inspection подготовьте вручную; случайные нормальные и дефектные фото разных моделей сравнивать нельзя.

## VisA

[Первичный репозиторий Amazon Science](https://github.com/amazon-science/spot-diff), [страница AWS Open Data](https://registry.opendata.aws/visa/).

Содержит четыре категории PCB1–PCB4 с установленными транзисторами, конденсаторами, чипами и другими элементами. Есть нормальные/аномальные изображения и маски. Данные опубликованы под CC BY 4.0. Подходит для исследования поиска аномалий и будущего обучения на нормальных примерах.

Для эталонного сравнения выбирайте снимки одной категории/варианта с подходящей геометрией. Нормальный снимок не гарантированно является точным эталоном любой аномальной платы из этой категории. Не смешивайте другие категории VisA с платами. Полный набор в проект не скачивался и в архивы не включён.

## ChangeChip и CD-PCB

[Статья авторов](https://arxiv.org/abs/2109.05746), [первичный код и пример пары](https://github.com/Scientific-Computing-Lab/ChangeChip).

В корне репозитория доступны `REFERENCE_IMAGE.JPG` и `INPUT_IMAGE.JPG`. Они могут быть полезны для локального исследования сравнения платы с компонентами. CD-PCB описан авторами как синтезированный набор из 20 пар. Его нельзя представлять как независимый тест на естественных производственных дефектах.

Явная лицензия на эти изображения в проверенном корне репозитория не найдена. Поэтому JPG не вложены в публичный исходный архив. Для локального скачивания после самостоятельного ознакомления с условиями:

```bat
.venv-win\Scripts\python.exe scripts\download_changechip_example.py --acknowledge-terms
```

Скрипт сохраняет данные в исключённую папку `local_data/changechip/`. Установщик этот скрипт не запускает.

## SolDef_AI

[Статья и описание авторов](https://www.mdpi.com/2504-4494/8/3/117).

Набор ориентирован на положение SMT-компонентов и состояние паяных соединений, включая снимки с разных точек. Полезен, если следующая задача — именно дефекты монтажа/пайки. Это отдельная задача обучения: текущий алгоритм выдаёт отличия, но не гарантирует распознавание непропая или избытка припоя. Перед загрузкой и передачей самого набора проверьте условия конкретного источника данных.

## Собственный независимый тест

Сохраняйте физические платы, партии и сессии съёмки раздельно между подбором параметров и итоговой проверкой. Нужны исправные платы с допустимой маркировкой и вариантами компонентов, а также подтверждённые дефекты. Учитывайте ложные тревоги от бликов, наклеек и параллакса. Наличие соответствий SIFT само по себе не доказывает совпадение модели и комплектации.

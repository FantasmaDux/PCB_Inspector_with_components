# Перенос и данные PCBA

## Windows

Переносите `PCB_Inspector_PCBA_Windows.zip` или исходники из Git. Установка: Python 3.12 x64, `setup_windows.bat`, затем `start_windows.bat`. Подробности в README. Установщик создаёт новое окружение `.venv-win` на целевом ПК. Mac-окружения и исполняемые файлы исходного компьютера в комплект не входят.

Для первой установки нужен интернет. После установки анализ локальный. Для ПК без интернета подготовьте Windows-колёса в `wheelhouse` по инструкции README и перенесите установщик Python. В текущем архиве готовых Windows-библиотек и автономного exe нет.

Windows-запуск не выполнялся на хосте автора по договорённости. Статическая подготовка не заменяет первый прогон `WINDOWS_CHECKLIST.md` на целевом ПК.

## Git

Source-архив содержит HTML/CSS/JS, Python, конфигурацию, тесты, генератор демонстраций и документы. PNG синтетических демонстраций создаются установщиком. Реальные платы, внешние исследовательские изображения и нейросетевые веса не включены. Код проекта — MIT; зависимости устанавливаются отдельно и имеют собственные лицензии.

Сохранены `.gitignore` и `.gitattributes`, `.bat` настроены на CRLF. Удалённый репозиторий не создавался и файлы не публиковались. После `git init` и `git add .` проверьте `git status`, затем сделайте commit и добавьте свой remote.

## Содержимое и чувствительные данные

В созданных исходниках нет личных учётных данных, токенов, API-ключей и абсолютных путей исходного пользователя. Демонстрации синтетические и созданы генератором; EXIF исходных фотографий в них нет.

Для настоящих фотографий, эталонов, производственных данных и отчётов используйте `local_data/`, `private/` или `reports/`: эти каталоги исключены из Git. Архиватор использует список разрешённых каталогов и также не включает эти папки, окружения, `.git`, `.DS_Store`, `.env` и логи.

Если вручную добавить настоящие фото в `samples/` или `docs/`, они могут попасть в Git/ZIP: эти каталоги предназначены для публикации. Исключения не действуют на уже отслеживаемые Git-файлы или принудительное `git add -f`.

JSON-отчёт содержит проверяемый снимок, эталон и карты. Перед передачей такого файла оценивайте чувствительность изображений, маркировки и комментариев. Сохранение истории в браузере не создаёт файлов внутри проекта.

При первом открытии PCBA копирует доступные старые записи в собственный ключ localStorage, сохраняя исходное хранилище v1. Для другого компьютера нужны экспорт/импорт JSON. Простое копирование папки не переносит браузерную историю.

## Пересборка архивов

```bat
.venv-win\Scripts\python.exe scripts\package_project.py
```

Windows-архив включает синтетические PNG. Source-архив содержит генератор и manifest, а PNG создаёт `setup_windows.bat`. Проверяйте новый состав перед публичной публикацией после добавления собственных файлов.
